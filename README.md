## Local Development Info
1. Create API keys for [Google Maps](https://mapsplatform.google.com/lp/maps-apis/) and [Gemini](https://aistudio.google.com/app/apikey)
2. Create `secrets.properties` file in the root of the application, should look something like this:
```properties
MAPS_API_KEY=<api-key-here>
GEMINI_API_KEY=<api-key-here>
```
3. Run the app through Android Studio!
