Technical Overview

Tech Stack

Bevr is a modern Android application built with the latest technologies to ensure a robust and fluid user experience.

  • Language: Kotlin
  • UI: Jetpack Compose
  • Architecture: MVVM with Clean Architecture principles
  • Database: Room for local persistence
